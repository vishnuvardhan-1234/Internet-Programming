# Online Job Portal

Applicants browse/search vacancies, save jobs, apply with resumes and privacy settings. Directors post vacancies and review applications. Admin approves directors and views reports.

## Dataset files
- `data/vacancies.csv`
- `data/users.csv`

## Notes
This is a functional starter scaffold with login, role-aware pages, dataset search, posting, saved records, applications/requests and admin approval/report views. Extend domain-specific forms and validation for final submission. For real deployment add CSRF protection, rate limiting, file type/size validation, audit logs, password reset and production server configuration.
